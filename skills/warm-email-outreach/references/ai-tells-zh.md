# 中文邮件 AI 味词表（外联专用）

中文外联邮件（触达国内开发者、商务合作、求 introductions）的识别逻辑与英文略有不同：中文商务邮件本身有礼貌传统，致命的不是"礼貌"，而是**模板化的客气 + 英文直译腔 + 零专属细节**。与 shuorenhua 通用词表的关系：黑话类（赋能/抓手/闭环）沿用其处理；这里只收邮件场景的高频项。

## 1. 一票否决（任一命中即重写）

### 1.1 无锚点赞美

| 病灶 | 替代 |
|---|---|
| "久仰大名" | 引对方一件具体的事："你在 X 大会上讲的那个 Y 案例" |
| "拜读了您的大作，受益匪浅" | 引文中一个具体论点并接真问题 |
| "您在 X 领域深耕多年，令人敬佩" | 删，直接说事 |
| "贵司的产品非常出色" | 引一个具体功能/版本/数字 |

### 1.2 万能开头

| 病灶 | 替代 |
|---|---|
| "冒昧打扰，还望海涵" | 删。第一句直接是钩子 |
| "尊敬的先生/女士" | 有名字用名字；没查到名字就不发（研究不合格） |
| "您好！我是 XX 公司的 XX，很高兴认识您" | 自我介绍后置一句；开场是对方 |
| "希望邮件找到您时一切都好"（英文直译腔） | 删 |
| "无意间看到您的分享" | 换成确切出处："在 X 群看到你那条关于 Y 的消息" |
| "今天联系您是想和您聊聊..." | 删掉宣告层，直接说事 |

### 1.3 元话语自证

| 病灶 | 为什么致命 |
|---|---|
| "这是一封一对一的邮件，不是群发" | 实锤式此地无银 |
| "长话短说" / "我就不多占用您时间了" | 短不需要宣告；宣告了通常并不短 |
| "抱歉打扰，如果打扰还请见谅" | 双重道歉=双重打扰 |
| "不确定您是否方便，如果不方便忽略即可" | 给了忽略的许可还占三行 |

### 1.4 空洞 CTA

| 病灶 | 替代 |
|---|---|
| "期待您的回复" 作为唯一请求 | 一个能一句话回答的具体判断题 |
| "不知道您是否有兴趣了解一下" | 把"了解"换成一个具体物件："看看这两页的草案" |
| "方便的话约个时间聊聊？" | 首触禁用；先给低成本请求 |
| "欢迎随时交流" | 删 |

## 2. 高危项（命中即改）

### 2.1 结构指纹

- **三段排比 / "不仅...而且...更..."**：二元三元拔高，删前半直接说结论。
- **bullet 列卖点**：1:1 邮件里出现"我们的优势：1. 2. 3."即推销模板。最多一处双元素对比。
- **每句等长、全程书面语**：允许短句（"值得吗？"）、允许一句一段。
- **破折号成串**（中文里用"——"做长解释）：中文邮件的 AI/翻译腔指纹，拆句或用逗号。
- **主题行营销腔**："诚邀共建 XX 新生态"、"关于战略合作的机会"——主题行写具体语境："你那条计费翻倍的帖子"。

### 2.2 过度礼貌堆叠

| 病灶 | 替代 |
|---|---|
| "不知是否方便劳烦您百忙之中..." | "能不能..." |
| "烦请您拨冗审阅" | "帮我看一眼" |
| "如蒙不弃" / "若承蒙慨允" | 删，直接说事 |
| "再次为打扰您致歉" | 全文零道歉 |

### 2.3 英文直译腔（中英混写外联的高发区）

| 病灶 | 替代 |
|---|---|
| "我真的很想听听你的想法"（I'd love to hear your thoughts 直译） | "你觉得这个划分成立吗" |
| "我冒昧地认为"（I humbly think） | "我的判断是" |
| "提前非常感谢"（Thanks in advance 直译） | 删或"先谢了"（口语一层即可） |
| "随信附上一些背景，希望有所帮助"（Context if useful 直译） | 背景直接写进正文该在的位置 |

### 2.4 问句失衡

- 恰好 1 个问句；客套问句（"最近忙吗？"）在陌生邮件里计为空洞 CTA，删。

## 3. 密度信号（单个放行，扎堆即改）

- 商务黑话沿用 shuorenhua 处理：赋能 / 抓手 / 闭环 / 沉淀 / 打法 / 对齐颗粒度。
- 垫片连用："期待您的回复"+"祝工作顺利"+"顺祝商祺"三个全上。留一个。
- 敬语全程满格（每个"您"都带"您方""贵方"）：一层礼貌即可，过满像客服机器人。
- "深受启发 / 收获很大 / 学到了很多" 连续出现：一次且必须锚定具体内容。

## 4. 正向参照（人味从哪来）

- 一个带出处的细节："你在 X 帖子里写的'账单三个月翻了三倍'"。
- 一句白话判断："这个数没人替你核过，这就是我们在做的事。"
- 短："两句话说完我们是什么"而非"请允许我用三个段落介绍"。
- 口语允许："这事挺急的不是因为我们要推，是因为你的续约在月底。"
- 真实署名：名字 + 一行身份 + 链接。"此致敬礼"墙、公司抬头墙都删。
