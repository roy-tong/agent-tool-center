# warm-email-outreach

给 AI 用的外联邮件 skill：替用户写"千人千面、不像 AI、先抹陌生感拉近距离再谈正事"的 1:1 外联邮件。规则提炼自 AgentMeasure 2026-08/09 的真实外联存档（回复率对照、封禁词门禁、事故复盘、LinkedIn/顾问/案例客户触达批次），关键结论均标注了来源文档。

## 文件

- `SKILL.md` — 主规则：发件前研究清单、邮件版防 AI 识别分级、结构法（抹陌生感→拉距离→再谈正事 + 软 CTA 阶梯）、四个场景包、节奏与放弃纪律、输出合同（研究摘要 + 草稿 + 三项自检）
- `references/ai-tells-en.md` — 英文邮件 AI 味词表（含本项目实测封禁句）
- `references/ai-tells-zh.md` — 中文邮件 AI 味词表
- `references/before-after.md` — 4 组 Before/After（真实邮件脱敏改写，附病灶标注与来源）
- `references/followup-templates.md` — 跟进决策树 + T1-T8 模板（新角度再触、闭环回执、LinkedIn、事故修复、求转介绍等）

## 与相邻 skill 的分工

| | 管什么 | 边界 |
|---|---|---|
| **warm-email-outreach**（本 skill） | 所有 1:1 外联邮件的通用底盘：研究、防 AI 味、结构、节奏、输出合同 | 群发营销邮件（newsletter/drip）不管；求评场景路由走 |
| **expert-review-outreach** | 求评式外联（Raju 模式）的特化深度规范：七要素、硬门、发送器纪律、深钩/矩阵两级产能 | 是本 skill"冷触达/暖回访"在"请对方评审具体物件"场景下的强化版；命中即按它的更严规则执行 |
| **shuorenhua** | 一般文本的去 AI 味改写 | 邮件场景的 AI 味致命项与文章不同（通用性>文笔腔），邮件用本 skill 的分级与词表；非邮件文本归它 |

一句话：写任何外联邮件先加载本 skill；如果这封信的目的是"请对方评审我的仓库/规格"，再叠加 expert-review-outreach。
