# 报告模式：全面、完整、叙述简单清晰

## 定位

报告的读者要「查」和「引用」，不是被取悦。**结构化在报告里是正当的**：目录、编号、小标题、bullet、表格都是报告的正常形态，不算 AI 味。要清掉的是模板腔——空话开头、套话收尾、每节同款「综上所述」、把结构当成内容本身。

北极星：读完能复述出「结论是什么、依据是什么、还缺什么」。

默认语域：**正式、清楚、可核查**。按读者和用途调节亲疏，不端官腔，也不为了“活人感”硬加口语和笑点。

## 一、全面完整怎么落地

### 从零写：信息架构

按报告目的取用，重要判断的依据与限制不能缺席：

```
背景与问题（为什么做这件事）
  → 方法与口径（怎么做、数据从哪来、怎么算的）
  → 发现（分层展开，证据在前判断在后）
  → 结论与建议（结论强度匹配证据强度）
  → 风险与限制（哪里站不住、什么条件下不成立）
  → 附：数据与来源
```

「风险与限制」经常被砍，但它是报告可信度的一半——一份没有边界的报告读起来就像推销。

### 改写与压缩：信息不丢

- 原文每个信息点（事实、数字、判断、动作、条件）在输出里可追溯，这是硬指标
- 压缩顺序：先压模板（套话、重复、空转），再压冗余论证，最后才压事实细节
- 压缩后如果某个结论失去了支撑它的证据，把结论降级或删掉，不是把证据删了留结论

### 口径纪律

- **分母写清**：「转化率 12%」必须能回答「12% of what」；「样本 200 条」写清从哪个池子抽的
- **来源可核查**：每个关键数字有出处（来源名+时间）；访谈写清是谁（或匿名编号+身份类型）
- **不编造**：没拿到的数据标`【待填：需要XX数据】`，不用「约」「据估算」糊弄
- **诚实降级**：证据不够就把结论强度降下来——「数据显示」→「样本提示」→「证据不足，无法判断」。宁可短，不可虚
- **反对过度规律化**：把零散证据硬拼成「三大趋势五条规律」是 AI 味的重灾区。证据只支撑到哪一步就写到哪一步，允许报告里出现「这两个案例方向相反，尚无法解释」

## 二、叙述简单清晰怎么落地

句法规则（通用底线 1.1 的翻译腔清洗在这里全量适用），报告特有的三条：

1. **一段一个落点**。段首句是这段的主张，后面是支撑。读者只读每段第一句就能抓住报告骨架
2. **主语短、动词靠前**。「我们公司在为银行卡中心构建的基于多源数据的风控系统于三季度上线」→「我们公司给银行卡中心建的风控系统三季度上线了。系统融合多源数据。」
3. **判断句直给**。「综合多方面因素考量，该方案在整体上呈现出较为可观的应用前景」→「这个方案值得投，理由三条」。删掉「较为」「呈现出」「可观」这类垫词

### 商务语域的界线

| 可用 | 不用 |
| --- | --- |
| 行业共识术语（权益库、策略引擎、履约、增量归因） | 自造词、无认知基础的英文缩写（见通用底线 1.3） |
| 书面语、数据表述、谨慎的限定（「在本次样本范围内」） | 官腔堆叠（「进一步」「不断」「持续深入」连用） |
| 直接的判断和取舍（「建议先做A，因为B」） | 营销腔（「助力企业腾飞」「打造行业标杆」） |
| 小标题、编号、表格、bullet | 每节同款的总结套话、空转的「框架图」 |

## 三、报告场景检查清单

改完或写完，逐项过：

**完整性**
- [ ] 读者需要的背景、方法、发现、结论与限制有交代；短备忘录可以合并
- [ ] 每个关键数字有来源；分母口径写清
- [ ] 每个结论的强度匹配它的证据强度；推测没写成「表明」
- [ ] 限制和反例写出来了，没只报喜

**清晰度**
- [ ] 只读每段第一句能抓住骨架
- [ ] 长定语链、被动堆砌、名词化空动词已清
- [ ] 表格用于精确对照（参数/价格/竞品），不当段落写
- [ ] 术语过三问（通用底线 1.3）

**去味**
- [ ] 空话、机械二元对比和无证据的金句已清；有真实区分的对比保留
- [ ] 无「值得注意的是」式元话语——直接说事实
- [ ] 每节结尾没有同款总结腔
